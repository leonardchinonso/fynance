fynance API Reference

Base URL: http://localhost:7433

All endpoints are prefixed with /api. The server is a local, single-user Axum application. The API is used by the browser UI and by external agents (LLM-powered categorization, data extraction).

Authentication

Browser requests from 127.0.0.1 (loopback) need no authentication. All requests pass through to handlers without a token.

Programmatic clients (scripts, agents, anything not on loopback) must supply a bearer token:

Authorization: Bearer fyn_<hex>

Tokens are created via the CLI: fynance token create --name my-agent

Docker note: In Docker, FYNANCE_HOST=0.0.0.0 is required for port mapping. This makes all connections non-loopback inside the container, so bearer token auth is required for all API calls.

Conventions

TopicConvention
MoneyDecimal strings ("123.45"), never floats. Negative = money out, positive = money in.
DatesISO 8601: YYYY-MM-DDTHH:MM:SS for datetimes, YYYY-MM-DD for dates, YYYY-MM for months.
Paginationpage (default 1) + limit (default 25). Response includes total, page, limit.
CurrencyISO 4217 codes (GBP, USD, EUR).
IDsUUIDs for transactions, categories, investments. User-chosen slugs for accounts, profiles.
Content-Typeapplication/json unless noted (multipart endpoints use multipart/form-data).
Multi-value paramsComma-separated in a single query param: accounts=monzo-alex,revolut-alex.

Error Handling

All errors return a JSON body with a consistent shape:

{
  "error": "human-readable message",
  "code": "machine_readable_slug"
}

Delete an account. Fails if referenced by transactions, holdings, or investment events. Defaults to a soft delete (sets is_active = 0); pass ?hard=true to permanently remove the row. Either way the account must be empty first. A hard delete also removes the account's ingestion-checklist rows.

curl -X DELETE "http://localhost:7433/api/accounts/monzo-alex?hard=true"

  "ok": true,
  "hard": true
}
